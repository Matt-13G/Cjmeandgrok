# پنل مدیریت کارخانه جویس و سالت

پنل مدیریتی داخلی تحت وب برای کارخانه تولید جویس و سالت.

## قابلیت‌های اصلی
- پروفایل کامل و تحلیلی هر محصول/طعم
- مدیریت تولید
- مدیریت انبار و موجودی
- ثبت و تحلیل فروش
- مدیریت خرید مواد اولیه
- محاسبه حاشیه سود
- داشبورد مدیریتی

## تکنولوژی‌ها
- Django
- PostgreSQL
- HTML/CSS/JavaScript
